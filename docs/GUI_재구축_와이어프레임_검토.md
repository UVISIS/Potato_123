# [2026-07-11] GUI 재구축 와이어프레임 목업 검토 및 역할분배

## 배경

소진님 이탈로 GUI 처음부터 재구축 필요. 기존에 소진님이 작성한
`MRO_UIUX_와이어프레임_기능명세.docx` (7페이지, 2026-06-12)를 기반으로
Figma 스타일 인터랙티브 목업(`MRO_wireframe_mockup.html`, `docs/` 폴더 첨부)을 만들었어.
백엔드 API(routers/functions)는 이미 완성돼 있어서 화면-API 매핑 관점으로 검토해줘.

**보는 법**: 파일 다운받아서 브라우저로 열면 됨. 상단 "캔버스 보기"에서 8개 프레임
전체 조망, "프레임 보기"에서 페이지별 확대 + 팝업 인터랙션 확인 가능.

## 페이지별 기능 요약 + 원본 대비 변경점

| # | 페이지 | 핵심 기능 | 원본(소진 스펙) 대비 변경 |
|---|---|---|---|
| 1 | 메인 대시보드 | 부품 재고 테이블 + 우측 기체별 D-Time 게이지(기체/엔진 탭) | 게이지를 계기판 스타일로 시각화, 기체/엔진 탭 전환 추가 |
| 2 | 부품 관리 | 목록/신규등록/수정 팝업 | 원본 그대로, 팝업 필드 동일 |
| 3 | 입출고 관리 | 입고표/출고표 좌우 배치 + 등록 팝업 | 원본 그대로 |
| 4 | 안전재고 관리 | 재고비율/상태 배지 + 부족·경고 카드 + 다음발주일 | 원본 그대로, 배지 색상만 구체화 |
| 5 | 기체 관리 (신규) | 기체 목록/등록/기종 등록 + 우측 부품정보(TBO) | 원본 3단 레이아웃(좌 목록/중 테이블/우 부품정보) 복원 |
| 6 | 정비 이력 | 정기/비정기/교체부품 3열 | 원본 그대로 |
| 7 | 주기정비 현황 (조회전용) | 기체/엔진/프로펠러/TRP + MSB 잔여상태 5칸 | 원본 5칸 구성 복원 (좌측 재고부족 패널 포함) |
| 8 | **발주/구매관리 (제안, 주황 라벨)** | 환율 Z-score, 상/하반기 저점예측, 다음구매시기+예상금액 | **원본 7페이지엔 없던 화면.** 안전재고관리 하단 2줄로만 존재했는데, 교수님이 요청한 핵심 데모 기능이라 별도 프레임으로 추가함 |

## Supabase 재확인 결과 (2026-07-12)

Supabase 재연결 후 4개 항목 실데이터 확인 및 가능한 범위에서 직접 수정 완료.

| 항목 | 확인 결과 | 조치 |
|---|---|---|
| `bom` 테이블 정비유형 6종 | 100H/200H/500H/Engine_100H/200H/300H/TRP_100H 등 **모두 입력 완료** (342건, DA40NG/DA42NG 전체 커버) | 별도 조치 불필요 |
| `parts_inventory` 위치 정보 | 청주/무안 분리는 사라졌으나, 16건 중 13건(81%)이 `location` NULL 상태였음 | **직접 수정**: NULL 13건 → `중앙창고`로 일괄 업데이트 완료 (중앙창고 단일화 방침 반영) |
| `components.unit_price_eur` | 115건 중 29건만 입력 (86건 NULL, 75%) | 실제 구매단가 데이터라 임의 입력 불가 — **데이터 입력 필요** |
| `parts_transactions.unit_price_eur` | 24건 전부 NULL (0%) | 위와 동일, 거래 시점 단가 입력 필요 |
| `purchase_orders` | 테이블 자체가 0건 (발주 이력 없음) | 8번 페이지 "구매 이력" 계열 표시는 현재 데이터로 불가 |
| `aircraft_components.tbo_hours` (신규 발견) | 37건 전부 NULL (`install_hours`는 37건 다 있음) | 5번 페이지 TBO 표시 불가 — **실제 TBO 스펙값 필요, 임의 입력 불가** |

**코드 수정 여부**: 위 항목 중 코드 버그로 인한 것은 없음 — 전부 실제 값 미입력 상태라 코드가 아닌 데이터 입력이 선행되어야 함. `parts_inventory.location`만 방침이 명확해 직접 채워 넣었고, 나머지(단가·TBO)는 실제 구매/정비 스펙 값이 필요해 임의로 채우지 않았어.

**다음 액션 필요**: `unit_price_eur`(components/parts_transactions)와 `aircraft_components.tbo_hours` 실측값 확보 방법을 정해야 함 — 재림님 쪽에 원본 스펙 문서 있는지 확인 부탁.
