# 비용 산정 모델 — 관부과세·항공운임·비행시간 기반 구매시기 (피드백 반영)

**관련 함수:** `fn17_calc_landed_cost`, `fn18_forecast_purchase_timing`
**엔드포인트:** `POST /procurement/landed-cost`, `GET /procurement/forecast/{aircraft_id}`

## 1. 관부과세 산정 기준

| 항목 | 계산식 | 근거 |
|------|--------|------|
| 과세가격(CIF) | FOB(상품가) + 운임 + 보험료 | 관세법 제30조 |
| 관세 | CIF × 관세율 | HS코드별 관세율 (파라미터) |
| **학술연구용품 감면** | 관세 × (1 − **0.80**) = 관세의 20%만 | **관세법 제90조** (감면율 100분의 80) |
| 부가세 | (CIF + 관세) × **10%** | 부가가치세법 제29조② |

- **감면 적용 근거:** 향후 정비 기자재는 청주대 부설 비행교육원(=학교)에서 학술연구·교육·실험실습용으로 수입 → 관세법 제90조 학술연구용품 감면 대상. **관세의 80% 감면**(관세의 20%만 납부).
- **민간항공기 부품 0% 가능성:** 다수 항공부품은 「민간항공기 무역에 관한 협정」으로 기본 관세율 0%. 따라서 `customs_duty_rate`는 HS코드별 파라미터로 두고 기본 0.0.
- ⚠️ 학술감면은 수입신고 시 용도 증빙·사후관리(3년) 요건 충족 전제 → 본 계산은 **예상치**.

## 2. 직구 전환 절감 효과

`fn17`이 두 방식을 비교 산출:

- **기존 대행(JCA 등):** CIF + 관세(감면 미적용) + 부가세 → 합계 × (1 + 대행수수료율)
- **직구:** CIF + 관세(학술감면 20%) + 부가세
- 절감액 = 대행 − 직구, 절감률(%) 반환

절감 원천 두 가지: ① 대행 수수료 제거 ② 학교 명의 직구 시 학술감면 적용.

> ⚠️ `agent_markup_rate`(대행 수수료율) 기본값 0.12는 **placeholder**. JCA 실제 계약 수수료 데이터로 교체 필요.

## 3. 항공 화물 요금

`fn17`이 3가지 방식 지원 (우선순위: 총액 > kg당 > 팔레트당):

- `freight_total_eur` (총액)
- `freight_per_kg_eur` × `weight_kg`
- `freight_per_pallet_eur` × `pallets` ← **kg당 책정이 모호할 때 팔레트 기준**

> ⚠️ 실제 운임 단가는 **조사 후 입력 필요**(유럽→인천 항공화물, 포워더 견적 기준). 현재는 호출 시 파라미터로 주입.

## 4. 환율

- 기본 고정 대략치 `DEFAULT_EXCHANGE_RATE = 1685.0` (EUR→KRW)로 **계산이 작동**하도록 처리.
- 운영 시 `fn8.get_exchange_rate()['exchange_rate']` 최신값을 `exchange_rate`로 주입 권장.

## 5. 비행시간 기반 구매시기 예측 (fn18 — 시뮬레이션 핵심)

단순 재고 가시화를 넘어 **비행시간 → 정비 도래일 → 부품 발주 시기**를 계산:

| 가정 | 값 | 근거 |
|------|----|------|
| 연간 총비행시간 | **725h** (기본) | 700~750h 중앙값, 안전 고려(피드백) |
| 하루 최대 비행 | 6.5h (참고 상한) | 6~7h(피드백) |
| 캘린더 환산 | 시간/일 = 연간/365 ≒ 1.99h/일 | 운항일 분산 반영 |

계산 흐름:
1. 잔여 비행시간 = `due_hours − aircraft.total_flight_hours`
2. 도래까지 일수 = 잔여시간 ÷ (연간/365) → 도래일
3. 발주 기준일 = 도래일 − 리드타임(`reorder_points.lead_time_days`)
4. BOM 소요부품 × 현재고 → 부족분, 발주 권고(**초과/지금발주/발주예정/여유**)

- 청주/무안 공통으로 **실제 누적 비행시간** 기준. 기지별 분리 운용 시 가정 분기 예정.
