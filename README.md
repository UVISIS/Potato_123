# 비행교육원 가동률 극대화를 위한 항공 정비 자재 최적 구매 설정 시스템
---
## 프로젝트 소개
비행교육원의 가동률 극대화를 위한 항공 정비 자재 관리 및 최적 구매 설정 시스템입니다.
기종 2대의 비행시간 및 정비 주기를 관리하고 재고 부족 및 정비 임박 시 자동으로 알람보드를 통해 인지할 수 있도록 합니다.

| 이름 | 역할 | 담당 업무 |
